# ウォーターソート

同じ色の水を1本の試験管にまとめるパズルです。ブラウザだけで動きます（ビルド不要・依存ライブラリなし）。

- 6段階 × 10レベル = **60レベル**。段階が上がるごとに条件が厳しくなる
- すべての問題は**ソルバーで解けることを確認済み**
- ヒント（ソルバーが次の一手を提示）、戻す、試験管の追加、やり直し
- 目標手数と★3段階評価、進行状況はブラウザに保存
- 色・段数・空き本数・隠し色を自由に決めて遊べる**カスタム**モード
- 色に記号を重ねる表示（色の区別がつきにくい人向け）、ライト/ダーク対応、スマホ対応

## 遊び方

1. 注ぎたい試験管をタップすると持ち上がる
2. 注ぐ先をタップする。注げるのは「空の試験管」か「一番上が同じ色の試験管」だけ
3. 一番上でつながっている同じ色はまとめて流れ、入りきらない分は元に残る
4. すべての試験管が1色ずつそろえばクリア

キーボード: `Z` 戻す / `H` ヒント / `R` やり直す / `Esc` 選択解除

## 起動方法

`index.html` をブラウザで直接開けば遊べます。ローカルサーバーで開く場合:

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。GitHub Pages でリポジトリのルートを公開しても、そのまま動きます。

## 難易度の段階

| 段階 | レベル | 色の数 | 空き | 隠し色 | 戻す | ヒント | 試験管追加 | 難しさの目標 |
|---|---|---|---|---|---|---|---|---|
| 入門 | 1–10 | 3〜5 | 2本 | — | 無制限 | 無制限 | 1本 | 0.00〜0.20 |
| 初級 | 11–20 | 5〜7 | 2本 | — | 無制限 | 5 | 1本 | 0.05〜0.70 |
| 中級 | 21–30 | 7〜9 | 2本 | — | 10 | 3 | 1本 | 0.30〜0.92 |
| 上級 | 31–40 | 9〜12 | 2本 | — | 5 | 2 | なし | 0.60〜1.00 |
| 達人 | 41–50 | 8〜11 | 2本 | あり | 5 | 1 | なし | 0.50〜1.00 |
| 極 | 51–60 | 5〜8 | **1本** | — | 3 | 1 | なし | 0.60〜1.00 |

難しさを決める要素:

- **色の数**: 試験管の本数と必要な手数が増える
- **空きの試験管**: 2本→1本で一気に難しくなる（ランダムな配置の大半が解けなくなるため、一手の誤りが命取りになる）
- **最初から揃っている部分**: 同じ色が隣り合っている数に上限を設ける（上級は0）
- **隠し色**: 一番上以外の色が見えない。一番上になった段から見えるようになる
- **アシストの回数**: 戻す・ヒント・試験管追加の回数を段階ごとに減らす

各段階の最初のレベルはいつでも遊べます。段階の中では、1つ前のレベルをクリアすると次が解放されます。

### 問題の作り方

`js/levels.js` の `generatePuzzle` が、レベル番号から作ったシードで問題を生成します（同じレベルは常に同じ問題）。

1. 全色をシャッフルして試験管に詰める
2. ソルバーで解けることを確認する（解けなければ作り直し）
3. 「同じ色の上に注げるならそうし、あとは適当に注ぐ」素朴なプレイヤーを60回走らせ、解けなかった割合を**難しさ（0〜1）**とする
4. 難しさが段階の目標範囲に入る候補を4つ集め、段階の序盤なら易しい候補・終盤なら難しい候補を選ぶ

目標手数は、最短手順の探索（A*）で求めた手数です。探索が重い大きな盤面では近似解（重み付きA*）を使います。

カスタムで「空き1本・色が多い」のように解ける配置がほとんど無い設定にした場合は、完成形から逆向きに崩して必ず解ける問題を作ります。

### ★の数

目標手数以内なら★3。目標を超えると★−1、目標の1.5倍を超えるとさらに★−1、ヒントか試験管追加を使うと★−1（最低★1）。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目（ライト/ダーク）
js/puzzle.js      ルール（注げるか・注ぐ・クリア判定）と乱数
js/solver.js      ソルバー（重み付きA*）
js/levels.js      難易度の段階の定義と問題の生成
js/game.js        1プレイ分の状態（戻す・ヒント・隠し色・追加・★）
js/app.js         画面の組み立て・入力・アニメーション・効果音・保存
tests/            Node.js の組み込みテストランナーによるテスト
```

`puzzle.js` / `solver.js` / `levels.js` / `game.js` は DOM に依存しないので、Node.js からも読み込めます。

## テスト

Node.js 18 以上で:

```bash
npm test
```

全60レベルが解けること・難しさが目標範囲に入ること・同じレベルが常に同じ問題になること、などを確認しています。

## 難易度の調整

`js/levels.js` の `TIERS` を編集します。色の数・空き本数・隠し色・アシスト回数・難しさの目標範囲（`band`）を段階ごとに変えられます。

生成の手順を変えると既存レベルの問題も変わります。その場合は `GENERATOR_VERSION` を上げてください（シードが変わります）。
